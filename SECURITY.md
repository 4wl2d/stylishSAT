# Security

Security fixes are supported on the latest published 0.x release. Install updates from this repository's GitHub Releases.

Report vulnerabilities privately through [GitHub security advisories](https://github.com/4wl2d/stylishSAT/security/advisories/new). Include a minimal reproduction and affected version. Do not post credentials, private learner data or exploit details in public issues.

The app uses private local storage and verifies optional model downloads by SHA-256. Read the [privacy notes](docs/PRIVACY.md).
