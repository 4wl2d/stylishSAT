# Contributing

Bug reports, content corrections and focused pull requests are welcome. Read the [development guide](docs/DEVELOPMENT.md) and [version policy](docs/VERSIONING.md).

For bugs, include app/Android versions, device model, reproduction steps and expected/actual behavior. Remove personal responses, recordings and identifiers from attachments. For content corrections, include the exercise ID, disputed wording and supporting reasoning or a reliable reference.

Keep changes focused, explain the user-visible result and validation, preserve regression/migration fixtures, and update Unreleased in CHANGELOG.md. Do not include build output or models. Contributions use the repository's MIT license; retain third-party attribution.
